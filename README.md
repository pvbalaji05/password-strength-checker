Password Strength Checker

A beginner-friendly Python project that checks how strong your password is — right in the terminal!

---

Features

- Checks password against 5 security conditions
- Rates password as **Weak**, **Medium**, or **Strong**
- Shows exactly which conditions are missing
- Suggests improvements for weak passwords
- Keeps checking until you choose to quit

---

Password Conditions Checked

| Condition | Example |
|---|---|
| At least 8 characters | `password` |
| Uppercase letter | `A, B, C` |
| Lowercase letter | `a, b, c` |
| Number | `1, 2, 3` |
| Special character | `@ # $ %` |

---

How to Run

1. Make sure Python is installed → [python.org](https://python.org)
2. Download `password_checker.py`
3. Open terminal and run:

```bash
python password_checker.py
```

No extra libraries needed — only the built-in `re` module!
